VERSION 1.7

What it does

01

Checks your PDF

Bleed, embedded fonts, image resolution and colour, checked against your printer’s own rules. Works on a PDF alone, with nothing to upload.

02

Changes fonts safely

Map every font in an InDesign file to a new one, including text that styles alone would miss. Only fonts change, and the new file is checked before you download it.

03

Warns before print

Flags tiny or thin text, text already cut off in InDesign, and frames that sit too close to the trim edge.
